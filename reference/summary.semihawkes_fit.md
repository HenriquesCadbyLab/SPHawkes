# Summarize a fitted semi-parametric Hawkes model

Reports what the [`print()`](https://rdrr.io/r/base/print.html) method
does not: the study window the model was fitted over, the estimated
branching structure (how the observed events divide between background
and triggered), the range of each fitted background component, and how
the EM run terminated.

## Usage

``` r
# S3 method for class 'semihawkes_fit'
summary(object, ...)

# S3 method for class 'summary.semihawkes_fit'
print(x, ...)
```

## Arguments

- object:

  A `semihawkes_fit` object from
  [`fit_semihawkes()`](https://henriquescadbylab.github.io/spHawkes/reference/fit_semihawkes.md).

- ...:

  Currently unused.

- x:

  A `summary.semihawkes_fit` object.

## Value

An object of class `"summary.semihawkes_fit"`, a list with elements
`n_events`, `start_date`, `end_date`, `TT`, `crs`, `mu`, `A`, `llik`,
`triggered_share`, `background_share`, `n_background`, `n_triggered`,
`components` (a `data.frame` of per-component ranges), `n_iter`,
`stop_reason` and `llik_change`. Printed by
`print.summary.semihawkes_fit()`.

## Interpreting `A`

Because `g` and `h` are each normalized to integrate to 1, the branching
ratio `A` is the expected number of *direct* offspring generated by each
event. For a subcritical process (`A < 1`) it is also the long-run
proportion of events that are offspring rather than immigrants, so it
can be read directly as a triggered share. The empirical counterpart
reported alongside it is `1 - mean(bgprobs)`, the average fitted
probability that an observed event was triggered; the two agree when the
model fits well and the window is long relative to the triggering range.

## Examples

``` r
# \donttest{
# A quick fit to one year of the bundled simulated data: a coarse grid, a
# coarse triggering-kernel grid and two EM iterations keep it to a few
# seconds. Real analyses need finer settings and more iterations.
cache_dir <- tempfile("spHawkes_marks_")
fit <- fit_semihawkes(
  sim_events, sim_region,
  date_col  = "date",
  end_date  = "2022-01-01",
  cell_size = 1000,
  cache_dir = cache_dir,
  trigger_spatial_args = list(x_range = 2000, x_step = 250),
  trigger_window_dist  = 2000,
  n_iter  = 2,
  verbose = FALSE,
  seed    = 1
)
#> The modelled study period ends on 2021-12-29, the day after the last event. `end_date` (2022-01-01) is used only to select events and to label outputs.
summary(fit)
#> Semi-parametric spatio-temporal Hawkes fit
#> ------------------------------------------------------------
#> Events        : 98

#> CRS           : EPSG:32717
#> 
#> Parameters
#>   mu (baseline rate)     : 2.59201e-09  per unit area per day
#>   A  (branching ratio)   : 0.5504  expected offspring per event
#>   log-likelihood         : -1875.36
#> 
#> Branching structure (from fitted background probabilities)
#>   background :     57.5 events ( 58.7%)
#>   triggered  :     40.5 events ( 41.3%)
#> 
#> Fitted components (range over their support)

# }
```
