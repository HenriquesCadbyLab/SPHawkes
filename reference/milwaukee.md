# Drug-related deaths in Milwaukee County

A spatial point dataset of drug-related deaths recorded in Milwaukee
County, Wisconsin, from 2020 onwards. Each row represents one event
classified as `"Drug Related"` in the source records. Events have
non-missing geocoded locations and intersect the Milwaukee County
boundary supplied in
[`milwaukee_county`](https://henriquescadbylab.github.io/spHawkes/reference/milwaukee_county.md).

## Format

An object of class `sf` with one row per event and the following
variables:

- event_id:

  Integer. Sequential identifier created for this packaged dataset. It
  does not correspond to the source record identifier.

- DeathDate:

  Date. Recorded date of death.

- death_year:

  Integer. Calendar year of `DeathDate`.

- death_month:

  Date. First day of the calendar month containing `DeathDate`.

- death_week:

  Date. Monday of the calendar week containing `DeathDate`.

- death_day_of_week:

  Ordered factor. Day of the week, ordered Monday through Sunday.

- death_weekend:

  Logical. Whether `DeathDate` falls on Saturday or Sunday.

- geometry:

  An `sf` `POINT` geometry column in EPSG:26916.

## Source

Original records: Milwaukee County Medical Examiner.

Processed records and geocoded locations: the [Medical Examiner OpenData
Pipeline](https://github.com/UK-IPOP/open-data-pipeline). The packaged
dataset was constructed from the data release dated 2025-12-01.

Spatial boundary used to select events: U.S. Census Bureau county
cartographic boundary data, 2024, accessed through tigris; see
[`milwaukee_county`](https://henriquescadbylab.github.io/spHawkes/reference/milwaukee_county.md).

## Details

The data are represented as an `sf` object with `POINT` geometry in
NAD83 / UTM zone 16N (EPSG:26916). Coordinates are measured in metres
and are therefore suitable for the spatial distance arguments used by
[`fit_semihawkes`](https://henriquescadbylab.github.io/spHawkes/reference/fit_semihawkes.md).

The data were derived from Milwaukee County Medical Examiner records and
geocoded locations distributed through the [UK-IPOP Open Data
Pipeline](https://github.com/UK-IPOP/open-data-pipeline/releases). The
distributed version was constructed from the release dated 2025-12-01.

Construction retained records with `DeathType == "Drug Related"`,
`DeathDate >= "2020-01-01"`, and non-missing geocoded longitude and
latitude. Source coordinates were interpreted in WGS84 (EPSG:4326), then
transformed to NAD83 / UTM zone 16N (EPSG:26916). Points were retained
when they intersected the 2024 TIGER/Line boundary for Milwaukee County.

The dataset is provided for illustration, testing, and reproducible
examples. It is not an authoritative administrative release. Event
classifications, dates, and locations may contain errors or change in
later releases of the source data. The data should not be used to make
causal or policy claims.

The code used to construct the dataset is
`data-raw/make-milwaukee-data.R` in the package's GitHub repository,
<https://github.com/HenriquesCadbyLab/spHawkes>.
